## 🚀 How to Use This Project

You can view the portfolio online or run it locally on your computer.

### Option 1: View Online

1. Open the live website:
   https://allenjoylacuesta7.github.io/Portfolio/
2. Browse the navigation menu.
3. Visit the About, Skills, Projects, Open Source, and Contact sections.
4. Use the project filters to explore projects by technology.

### Option 2: Run Locally

**Requirements:**
- A web browser (Google Chrome, Microsoft Edge, Firefox, etc.)
- A code editor (Visual Studio Code recommended)
- Git (optional, for cloning the repository)

**Installation:**

1. Clone the repository:

   ```bash
   git clone https://github.com/allenjoylacuesta7/Portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd Portfolio
   ```

3. Open the folder in Visual Studio Code.

4. Open `index.html` in your browser.

   Alternatively, use the Live Server extension in Visual Studio Code for a local development preview.
